# 🚀 Roblox RBXMX Script Extractor

A fast, lightweight, web-based tool designed to extract Luau scripts from Roblox Studio `.rbxmx` (XML) files and organize them into a single, structured Markdown (`.md`) file.

---

## ✨ Features

* **Instant Script Extraction:** Automatically identifies and parses `Script`, `LocalScript`, and `ModuleScript` objects.
* **Pure Client-Side Processing:** Your files are processed entirely in your browser using HTML5/JS. No data is ever uploaded to external servers.
* **Clean Code Formatting:** Outputs Lua/Luau code blocks with clean syntax highlighting ready for documentation or review.
* **Easy Drag & Drop:** Drop your `.rbxmx` file directly into the browser to extract scripts in seconds.

---

## 🛠️ How to Use

1. Export your model or project from **Roblox Studio** as a `.rbxmx` file (`Selection > Save to File...`).
2. Open the **[Live Web Tool](https://KULLANICI_ADIN.github.io/rbxmx-script-extractor/)**.
3. Drag and drop your `.rbxmx` file into the box (or click to select).
4. The tool will parse the project hierarchy and automatically download a `.md` file containing all extracted scripts.

---

## 💻 Local Setup & Development

If you'd like to inspect the code or run it locally without using GitHub Pages:

1. Clone or download this repository.
2. Open `index.html` in any web browser.
3. That's it! No additional dependencies or build steps required.
